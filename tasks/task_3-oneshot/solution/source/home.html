Clausewise is the contract intelligence API for product teams building legal, procurement, and compliance workflows. Extract clauses, score risk, and suggest redlines from a single POST — with citations back to the source paragraph.

Start integrating Read the docs
SOC 2 Type II No training on your data p95 < 1.4s 
# Review an NDA and get clauses, risk, and redlines
curl https://api.clausewise.dev/v1/contracts/review \
  -H "Authorization: Bearer $CW_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "document_url": "https://files.acme.co/nda-v3.pdf",
    "playbook": "mutual-nda-default",
    "jurisdiction": "US-DE",
    "include": ["clauses", "risk", "redlines"]
  }'

// 200 OK — application/json
{
  "id": "rev_8fK2a1xQ",
  "status": "completed",
  "clauses": 23,
  "risk_score": 0.34,
  "redlines": 4
}

What you get

Three primitives, one API call.

Mix and match the parts you need. Everything returns structured JSON with paragraph-level citations so your UI can highlight exactly the right line.

Clause extraction

Identify, classify, and normalize 180+ clause types — from indemnification and limitation of liability to assignment, change of control, and data processing addenda. Returns structured spans with confidence and source citations.

Learn more

Risk scoring

A calibrated 0–1 risk score per clause and per document, mapped to your playbook. Customize thresholds, override rules, and explain the score with a human-readable rationale your legal team can sign off on.

Learn more

Redline suggestions

Generate counterproposal language anchored to your fallback positions. Output as plain text, tracked-change DOCX, or a JSON diff your editor can render inline. Every suggestion cites the playbook rule it came from.
