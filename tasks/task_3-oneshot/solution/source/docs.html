Review a contract

Submit a previously uploaded contract for AI-powered clause analysis. The endpoint returns a structured review job that you can poll, stream, or receive via webhook when complete.

POST /v1/contracts/{contract_id}/review

Starts an asynchronous review against a playbook of your choice. Most reviews complete within 8–14 seconds depending on document length and the number of clause categories requested. Each review consumes one credit per 5,000 tokens of input text.

Idempotent by default

Pass an Idempotency-Key header to safely retry network failures. Duplicate keys within 24 hours return the original review object.

Parameters

All parameters are sent as JSON in the request body. Path parameters are resolved from the URL.

NameTypeRequiredDescription
contract_id string required The identifier of the uploaded contract, e.g. ctr_8Tq2v…. Returned by POST /contracts.
playbook_id string required The playbook used to score and redline the contract. Use the default pb_default_msa or a custom playbook from your workspace.
jurisdiction enum optional One of us, uk, eu, ca, au. Defaults to the playbook’s governing law.
clause_types string[] optional Limit analysis to specific clause categories — e.g. ["indemnity","liability","termination"]. Omit to review all 47 supported types.
generate_redlines boolean optional When true, the response includes suggested edits with track-changes-compatible deltas. Default false.
webhook_url string optional HTTPS endpoint to notify when the review reaches a terminal status. Falls back to your workspace default if unset.
metadata object optional Up to 20 key/value pairs (≤500 chars each) for your own bookkeeping. Returned untouched on every webhook event.

Response

Returns a Review object with a status of queued or processing. Poll GET /reviews/{id} or listen for the review.completed webhook to receive the final result.

FieldTypeRequiredDescription
id string always Unique review identifier, prefixed rev_.
object string always The literal string "review".
status enum always One of queued, processing, completed, failed.
risk_score number conditional Composite 0–100 score (only present when status = completed). Lower is safer.
findings Finding[] conditional Ordered list of detected issues. Each finding contains a clause reference, severity, and rationale.
redlines Redline[] conditional Present when generate_redlines = true. See the Redline object.
created_at int always Unix timestamp (seconds) when the review was enqueued.
completed_at int | null conditional Unix timestamp when terminal status was reached. null until then.
Heads up: large documents

Contracts over 60 pages are split into chunks and processed in parallel. The webhook fires only once, after every chunk completes. Use expand=chunks to inspect per-chunk timings.
